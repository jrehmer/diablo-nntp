- `dexpirecache -i`: a run no longer takes time of the order of N squared for the N inodes still needed (`-i` minus the free inodes). It kept the N oldest empty files and links in a sorted list that every entry walked: with 400000 such files and N = 100000 a run took 422 s, now it takes seconds. The entries removed and their order are the same (D-305). Tests: `TestDexpirecacheInodeSet`, `TestDexpirecacheInodeTwoDays`.
