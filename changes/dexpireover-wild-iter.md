- dexpireover: `-w` with two or more empty groups that share a file name hash with a populated group it does not select no longer applies an empty group's range to the populated group's files (over file "bad file header", data files removed as stale): when no selected group is named in the over file the files are left alone, and `-v` says so (D-322). `dexpireover -a` no longer removes the files of a group's next iteration while its `ITER` has not been written yet (or the write was lost): a file is kept when the group's `ITER` is at most the file's iteration, as `doverctl clean` does (D-319). Like `doverctl clean`, it now also keeps the leftover files of a removed group whose iteration is at or above that of a group with the same hash; these have to be removed by hand for now (D-323).
