- `diablo`: an incoming connection is matched against the address entries of dnewsfeeds and diablo.hosts (IP, CIDR, wildcard IP, and the addresses host names resolve to) before any DNS lookup. The reverse lookup is done only when no address entry matches and a wildcard name entry exists, and then for at most 20 seconds; without a wildcard name entry an address that matches no address entry gets no lookup. A peer matched by an IP entry now logs and counts its statistics under its address, and one matched by a name entry under that name, not under its PTR name (D-242).
