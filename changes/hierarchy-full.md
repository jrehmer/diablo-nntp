- New `readergrouphash hierarchy-full` for new reader spools: as `hierarchy`, but every component of the group name except the last is a directory (`a.b.c` in `a/b/`, `e2e.x.gz` in `e2e/x/`; `hierarchy` joins a component of one character to the next one), so a group and the same name plus `.gz` (`e2e.x` and `e2e.x.gz`) never share a data file. The file names are those of `hierarchy`, and `hierarchy` itself is unchanged. An existing spool cannot be switched between the two yet: there is no conversion, and `doverctl convert` refuses it (D-325).
