- `dreaderd`: a checkgroups control message is acted on as INN's `docheckgroups` does with `doit` (an enhancement; D-53 had made it update descriptions only). Besides updating the descriptions of the groups it lists that exist, it creates the listed groups that do not exist (complete records; "(Moderated)" in the description makes a moderated group), corrects the moderated flag of existing groups, and removes the groups of the top-level hierarchies of the message that match the `dcontrol.ctl` newsgroups pattern and are not in the message. The additions, changes and removals are only made when there are not more than `/maxdocheckgroups/` of them (default 10, as in INN; set with a line `/maxdocheckgroups/:*:*:<number>` in `dcontrol.ctl`); beyond that they are written to the control log (`doit=logfile`) as the `dgrpctl` commands that make them, and only the descriptions are updated. A site that took the real ISC checkgroups (about 1,900 groups) before did not get any new groups; now it needs the limit raised once to create them. Narrow the third field of the `checkgroups` line in `dcontrol.ctl` if you have local groups in a hierarchy of the message. Tests: `TestReaderCheckgroupsControl`, `TestCheckgroupsInn*`, `TestISCControlCheckgroups*`.
