- dsyncgroups: with `-G` and `-D`, local groups are deleted only when the last line of the file that is not blank is a line with only a `.`, like a list from a remote host, and the file was read without a read error (D-328). A file that was cut short deleted every local group it did not name; now a note is printed, nothing is deleted, and creating and updating go on. `-G` without `-D` is unchanged: the whole file is read, and a `.` line is no group. If you use `-G` with `-D`, end the file with a `.` line (empty lines after it are fine); a `.` in the middle does not end the file, and with a line that is not blank after the last `.`, `-D` deletes nothing (a note is printed), as with a file that has no `.`.
