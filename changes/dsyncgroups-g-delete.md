- dsyncgroups: with `-G` and `-D`, local groups are deleted only when the file ends with a line with only a `.`, like a list from a remote host (D-328). A file that was cut short deleted every local group it did not name; now a note is printed, nothing is deleted, and creating and updating go on. `-G` without `-D` is unchanged. If you use `-G` with `-D`, end the file with a `.` line and put nothing after it: a line after the first `.` is no longer read as a group, and with it `-D` deletes nothing (a note is printed), as with a file that has no `.`.
