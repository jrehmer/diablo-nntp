- `doverctl -m convert` no longer follows a symlink at the new name of a group's over or data file: `MoveFile()` removes whatever is at the destination name and creates the file with `O_EXCL`, so the link's target is not truncated and overwritten (D-332). `dexpireover` now removes all the temporary files an interrupted `-R` (or `-z`) leaves in a group directory, `.` plus exactly the name of one of the group's over or data files (or a data file name and `.gz`) in every layout; the md5 temporary data files and the temporary over files of every layout were never removed, and other dotfiles, also ones that only start like such a name (`.over.0.<hash>.backup`), are now left alone (D-333).
