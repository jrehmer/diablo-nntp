- `doverctl -m convert` no longer follows a symlink at the new name of a group's over or data file: `MoveFile()` removes whatever is at the destination name and creates a new file (mode 0644 less the umask) with `O_EXCL`, so the link's target is not truncated and overwritten (D-332). A conversion between two methods that give a group the same path (for example `md5-32:30\1` to `md5-32:40\1`, or `md5-32/32` to `md5-32/64` for some groups) no longer loses that group's over and data files with `-m`: a file already at its new name is left as it is, as without `-m`. `dexpireover` now removes all the temporary files an interrupted `-R` (or `-z`) leaves in a group directory, `.` plus exactly the name of one of a group's over or data files (or a data file name and `.gz`) in every layout; the md5 temporary data files and the temporary over files of every layout were never removed, and other dotfiles, also ones that only start like such a name (`.over.0.<hash>.backup`, `.o.0.<group>~`), are now left alone. Only temporary files of groups in the active file are removed, so a `-w` run leaves those of the groups it does not select, and those of a removed group stay (`doverctl clean` removes them) (D-333).
